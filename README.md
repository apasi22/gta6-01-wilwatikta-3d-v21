Open-world crime di kota pesisir fiktif **Wilwatikta**, Jawa, tahun 1998.
Main sebagai **Sugeng Wibowo**, kejar balapan siang di Pantai Kidul, kabur
dari WPD, dan selesaikan 12 misi cerita bersama kru: Agus, Wanto, Bambang,
Ratna, dan Slamet.

## Main

Buka `game/index.html` di browser desktop (offline, tanpa server). Three.js
sudah di-vendor di `game/vendor/`.

- **WASD** gerak · **Mouse** kamera · **E** masuk mobil · **Klik** tembak
- **Q** ganti senjata · **M** peta · **R** radio · **U** bengkel

## Kota

Enam distrik bernama: Pelabuhan Segara, Kampung Batik, Lorong Emas, Pantai
Kidul, Alun-Alun, Pasar Senja. Masing-masing punya toko, bengkel, dan
karakter sendiri. Peta GPS aktif, dispatch WPD dengan unit bernama + jarak,
slot senjata bernomor + harga, radio Gamelan FM 101.1, dan sistem respect.
